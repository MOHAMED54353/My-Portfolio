## About the Project

My personal portfolio showcases my technical skills, featured projects, and journey as a **Front-End Developer**.

Built with React and Vite, it combines a dark, modern UI with interactive 3D experiences, subtle animations, particle effects, and a fully responsive layout.

## Key Features

* **Dark Mode Aesthetic:** A modern dark-themed interface with strong visual contrast.
* **Interactive 3D Experiences:** Immersive 3D visuals created with Spline.
* **Smooth Animations:** Subtle motion effects and transitions across the site.
* **Particle Effects:** Dynamic particle visuals that add depth to the interface.
* **Fully Responsive:** Optimized layouts for desktop, tablet, and mobile.
* **Project Showcase:** Dedicated sections for selected projects and technical skills.
* **Modular Architecture:** Reusable React components and a clean application layout.
* **Fast Workflow:** Powered by Vite for quick development and efficient production builds.

## Getting Started

### Prerequisites

* Node.js
* npm
* Git

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/MOHAMED54353/<your-repo-name>.git

# 2. Navigate to the project directory
cd <your-repo-name>

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.

## Available Scripts

| Command           | Description                           |
| ----------------- | ------------------------------------- |
| `npm run dev`     | Starts the development server         |
| `npm run build`   | Creates an optimized production build |
| `npm run preview` | Previews the production build         |
| `npm run lint`    | Checks the code using ESLint          |
